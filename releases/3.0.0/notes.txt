xewe-os-modules 3.0.0

The module set 3.0.0: the six ready-made XeWe OS modules, each released on its own at 3.0.0 and
marked together by this tag. Projects pin the set: xewe.toml [modules] ref = "3.0.0".

MODULES

buttons, pins, scheduler, time, web-interface and wifi, all at 3.0.0. Each module's own release
(tag <module>/3.0.0) has its notes and test card; the links are below.

REQUIREMENTS

- XeWeCore >=3.0.0,<4.0.0 (requires_core of every module).
- xewe-os-tools 3.0.0 (its DEFAULT_MODULES_REF is "3.0.0"), ESP32-C3, C6 or S3 with
  arduino-esp32 3.x.

TAGS

- <module>/3.0.0, e.g. wifi/3.0.0: one module's release.
- 3.0.0: this set. No "v" prefix (the old v0.2.0 stays as it is).
