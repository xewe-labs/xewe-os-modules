wifi 3.1.2

Wi-Fi station setup and status. 3.1.2 removes the module's debug switch; joining, the scan and the
first-boot questions behave as in 3.1.1.

Removed

- XEWE_WIFI_DEBUG and the DEBUG_Wifi macro: the module no longer has a debug output. Its
  compile time defined constants section is empty; a project generated by xewe-os-tools 3.1.5
  shows no line for it. XEWE_WIFI_SSID and XEWE_WIFI_PSW are unchanged. A build that still
  defines the old name gets an unused define and no error.

Requirements

- XeWeCore >=3.1.0,<4.0.0 (requires_core).

Testing

What was tested, on which tree and with which result: release_card.md, generated by
scripts/release.sh --prepare 3.1.2 wifi and attached to this release.
