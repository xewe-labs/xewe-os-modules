wifi 3.1.0

Joins a WiFi network and keeps the connection alive. This release moves the module's values to the
configuration scheme of XeWeCore 3.1.0 (doc/config.md) and lets a project pre-answer the first-boot
network questions. It raises requires_core to >=3.1.0,<4.0.0, and its release card is generated from
the 3.1.0 test run (unit tests, module-alone and all-modules builds on c3, c6 and s3, and the board
session).

Changed since 3.0.0

- The define is XEWE_WIFI_DEBUG (was XEWE_MODULE_WIFI_DEBUG), in src/Wifi/Config.h with its three
  sections.
- First-boot values XEWE_WIFI_SSID and XEWE_WIFI_PSW. xewe modules generate writes them to the
  project's Config.h commented out; uncomment one and set it, or set it to INJECTED_FROM_DOTENV to
  take it from the dotenv file at build time (the usual way for the password).
- Both set: they are written to NVS, the scan is skipped and the join is tried three times; if all
  three fail, one "!" line is printed and the scan menu follows. Only the SSID set: the password is
  asked. Only the password set: ignored.

Requirements

- XeWeCore >=3.1.0,<4.0.0 (requires_core). Everything else as in wifi 3.0.0.
