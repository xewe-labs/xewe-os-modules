web-interface 3.1.1

The HTTP server and the console page. 3.1.1 brings the configuration file into its final form; the
server behaves as in 3.1.0.

Changed

- Config.h is in the final form of XeWeCore's doc/config.md: every text line a /* */ block comment,
  two sections between start and end marker lines ("default runtime values", "compile time defined
  constants"), a value the first boot asks for marked "asked at first boot" and defining its
  <NAME>_PROMPT. No define is renamed and no value changes. A project generated by xewe-os-tools
  3.1.5 shows the module's lines commented out; uncomment one to override its default.
- XEWE_WEB_INTERFACE_PORT and XEWE_WEB_INTERFACE_ROOT are default runtime values; the compile-time
  section is empty.

Requirements

- XeWeCore >=3.1.0,<4.0.0 (requires_core); depends on wifi.

Testing

What was tested, on which tree and with which result: release_card.md, generated by
scripts/release.sh --prepare 3.1.1 --all and attached to this release.
