time 3.1.0

NTP time sync and timezone detection. This release moves the module's value to the configuration
scheme of XeWeCore 3.1.0 (doc/config.md) and lets a project pre-answer the first-boot timezone. It
raises requires_core to >=3.1.0,<4.0.0, and its release card is generated from the 3.1.0 test run
(unit tests, module-alone and all-modules builds on c3, c6 and s3, and the board session).

Changed since 3.0.0

- New first-boot value XEWE_TIME_TZ_GMT_STR (src/Time/Config.h, a string literal GMT+HH:MM).
  xewe modules generate writes it to the project's Config.h commented out; uncomment it and set
  the offset, or set it to INJECTED_FROM_DOTENV to take it from the dotenv file.
- A pre-answer that parses skips the detection and the confirmation; the clock still syncs over
  NTP. One that does not parse falls back to the typed input.

Requirements

- XeWeCore >=3.1.0,<4.0.0 (requires_core). Everything else as in time 3.0.0.
