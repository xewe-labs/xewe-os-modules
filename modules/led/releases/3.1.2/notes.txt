led 3.1.2

The LED strip engine: 46 chipsets, 7 effects, brightness and colour order, with the first-boot
wizard. 3.1.2 gives the pin defaults one value for every chip; the strip behaves as in 3.1.1.

Changed

- XEWE_LED_PIN_DATA and XEWE_LED_PIN_CLOCK default to 4 and 3 on every chip. The chip-conditional
  defaults are gone. A release image or a project sets other pins with `xewe build --define` or in
  its Config.h; the README lists the Led Dock V2 pins per chip (c3 4/3, c6 20/19, s3 13/12).

Breaking

- A C6 or S3 build without an explicit pin value now drives GPIO 4 and 3 instead of 20/19 and
  13/12. Set the pins with `--define XEWE_LED_PIN_DATA=<gpio> --define XEWE_LED_PIN_CLOCK=<gpio>`
  or in the project's Config.h.

Requirements

- XeWeCore >=3.1.0,<4.0.0 (requires_core); FastLED as in 3.1.0.

Testing

What was tested, on which tree and with which result: release_card.md, generated by
scripts/release.sh --prepare 3.1.2 led led-web and attached to this release.
